## ▶️ How to Run

You can run the Python files in this repository on your local machine.

**Prerequisites:**

* Python 3 installed on your system.
* A code editor or terminal.

**Clone the repository:**

```bash
git clone https://github.com/Naveen25-As/DSA-Complete-Roadmap.git
```

**Navigate to the repository:**

```bash
cd DSA-Complete-Roadmap
```

Run a Python file using:

```bash
python filename.py
```

Replace `filename.py` with the name of the Python file you want to execute.
